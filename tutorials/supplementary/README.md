# Supplementary process demos

These tutorials teach tasks outside the paper's four experiments. Each uses an
external editable project, a notebook for explanation/configuration, and a saved
script for actual execution. They are small workflow demos, not paper artifacts.

- [Oxford-IIIT Pet](pet/README.md): image classification, explicit data splits,
  Trial/Formal fractions, resource budgets and score-versus-iteration plotting.

The [four paper-task demos](../paper/README.md) have separate historical task and
planner bindings. MJD, SuperNEMO and Cancer supplementary tutorials remain planned.
