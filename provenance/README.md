# Provenance and historical evidence

This directory records where task assets came from and what earlier validation
actually established. Read each record's date, source revisions and limitations
before applying it to a new checkout.

- [Migration record](MIGRATION.md) explains the framework/experiment separation.
- [Validation records](validation/) retain dated acquisition, composition and
  qualification evidence.
- [Legacy SIDERIUS archive](legacy_siderius/) preserves retired source and reports
  under their original ownership; its child READMEs explain each capture.

For current scientific task meaning, start with [tasks](../tasks/README.md).
For paper source/configuration pairs, use the
[paper artifact reference](../experiments/paper-artifacts.md). An archived passing
check does not qualify a changed task, dependency or deployment.
