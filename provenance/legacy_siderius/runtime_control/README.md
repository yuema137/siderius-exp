# Legacy C2 runtime-control archive

This directory preserves the validation-only runtime mechanisms used by the
V20 PR-C2 Gate-2 Lite harness. They are provenance, not supported SIDERIUS or
`siderius-exp` runtime APIs.

The archived modules own the C2 formal-stability channel and parent watcher,
the paired-arm environment-comparability policy, and the dated Gate control
flow that consumed them. No active task, experiment, or campaign imports these
modules. Reproduction requires the recorded historical SIDERIUS revision and
the archived C2 harness.

See the [preserved inventory](inventory.md) for detailed file descriptions and
original identities.

For current deployment guidance, see [deployments](../../../deployments/README.md).
