# DAVIS workflow demonstration

Use the [DAVIS tutorial](../../../tutorials/supplementary/davis/README.md) to
create your own external project. This workflow binds the existing bounded
future-frame task, operator-controlled Formal scope and all-Luna test routing.
It does not alter the original decoder, exact-L1 objective, MSE metric or Health
policy. Validation feeds search; Final clips remain unused.

The initializer copies this workflow into `experiments/workflow.json` beside
`davis-demo.json`. The JSON owns three-iteration defaults, clip fractions,
time/VRAM allowances and output location; the saved script executes it.
Trial starts with 15 training clips and Formal with 30, both using all 15
Validation clips. Epoch sampling remains full within each selected clip scope.

The [recorded demo](../../../tutorials/supplementary/davis/example/README.md)
completed three iterations and retained its first Health-invalid candidate.
Historical qualification launchers and their machine-specific settings remain
separate and unchanged. This is a teaching demo, not a paper artifact or a
promised score.
