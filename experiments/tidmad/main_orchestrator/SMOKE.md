# Short baseline-compatible orchestration smoke

Use one cleared orchestration H100 room first, the existing Codex baseline
harness and scoring route, and separate diagnostic state. No formal clock starts
until smoke, review, PR merges and paired tags are complete.

## Required evidence

1. The selected frozen common package is unchanged; installed infra is protected.
   Outer Codex settings, account, data/network/GPU rights and total budget match
   the agreed baseline controls. NoPrior contains no analysis/advice artifacts.
2. Read the toolkit entry and invoke supported native agents with real task
   inputs. Produce a small trained candidate using a short explicit epoch budget.
3. Export and submit through existing `tidmad-score`; obtain a complete-band
   receipt. Do not reduce the official scoring scope to manufacture a pass.
4. Exercise two iterations and two small parallel branches; show independent
   artifacts, failure recovery, continuing deadline and cleanup using the existing
   harness. Diagnostic guidance may request these actions only during smoke.
5. Collect artifacts/logs and clear smoke state before four formal fresh starts.

Framework/setup failures block launch. Agent strategy, voluntary tool choice,
model quality and unobserved hypothetical edge cases do not. Existing CPU/agent
witnesses may cover unchanged mechanisms; repeat only where integration changed.
Keep training short and report actual replay time rather than padding a fixed
long training schedule. Record the explicit smoke identity and limits before launch.

Full's candidate analysis/advice policy remains separately prepared for review;
matched Full deployment is not a prerequisite for the present NoPrior launch.
