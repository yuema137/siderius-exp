# MJD teaching experiment

This fixed workflow template belongs to the [MJD tutorial](../../../tutorials/supplementary/mjd/README.md).
Use that guide to initialize an external project; this JSON is not a standalone
launcher. Its relative task/routing paths resolve inside the initialized project.

The saved experiment owns three-iteration demo sizing and native resource
allowances. The runner fixes snapshot selection and per-epoch thinning and disables
Data Analysis/literature/advice. The initial treatment uses diagnostic result
authority. The unchanged
Majorana task owns official Train/Test roles, waveform preprocessing and AUC.
Official Test is used during search; there is no separate blind holdout here.

The historical qualification/campaign/demo profiles in the parent directory are
unchanged. The [recorded three-iteration demo](../../../tutorials/supplementary/mjd/example/README.md)
provides the completed API/GPU witness and its exact source provenance.
