# Pet tutorial experiment templates

These templates initialize a new external teaching project. Follow the
[Pet tutorial](../../../tutorials/supplementary/pet/README.md); do not edit these
tracked files as a user step.

`agents.json` explicitly selects current `native-timing-v1` planner behavior.
`workflow.json` contains fixed workflow flags and project-relative task/routing
paths; the tutorial copies it to `experiments/workflow.json` in your project.
The saved `pet-demo.json` owns the exposed iteration, fraction and budget settings.

This is a new treatment. The old two-iteration qualification and four paper-task
experiments retain their original identities.
