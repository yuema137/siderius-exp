# SuperNEMO teaching workflow

This fixed workflow is used by the [SuperNEMO tutorial](../../../tutorials/supplementary/supernemo/README.md).
Follow that guide to prepare event indexes and create an external project. This
JSON is a template; its relative task and LLM paths resolve in the copied project.

The initial experiment requests three iterations, Trial then Formal, one epoch,
one-percent training/evaluation scopes and native Luna test routing. It disables
Data Analysis, literature review and human advice. The initial treatment uses
diagnostic result authority and the task's explicit no-Health declaration;
native resource and scoreability checks still apply.

The task's original event split remains unchanged. Search uses training and
validation, never the reserved test partition. This is a supplementary workflow
demo, not a paper artifact or a replacement for historical experiment profiles.
Fresh API/GPU qualification is pending; offline readiness is not a training result.
